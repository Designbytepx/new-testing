How the score works

  • CygnosIQ is one number from 0 to 100 for the health of your company’s AI. Higher is healthier.
  • It has four parts, always in the same order: Value Delivered, Safe Use, Reliability and Spend Discipline.
  • Each part shows its state and how many points it moved the score.
  • Cygnos reads it from your own systems, on the same method every month, so one month can be set against the last.
